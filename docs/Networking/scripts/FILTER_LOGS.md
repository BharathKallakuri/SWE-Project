# Log Filtering & IST Conversion Guide (`filter_logs.py`)

A standalone Python utility for filtering, formatting, and analyzing logs generated by `FileTraceListener` and application modules (`Networking`, `Chat`, `Whiteboard`, `FileSync`, etc.).

---

## Key Features

1. **Automatic UTC to IST Conversion**: Converts UTC timestamps (`Z` suffix) from .NET's `TraceListener` to **Indian Standard Time (IST, UTC+05:30)** with millisecond precision.
2. **Convert All Logs (`--to-ist`)**: Batch converts timestamps across **all modules** in a log file without filtering out any records.
3. **Prefix Stripping**: Automatically strips noisy .NET trace listener prefixes (e.g. `UX Information: 0 : `) by default, while preserving multiline stack traces and continuation lines.
4. **Any Module Support**: Defaults to `Networking`, but easily filters for any module (`Chat`, `Whiteboard`, `FileSync`, `Cloud.Networking`, etc.) or multiple modules at once.
5. **Auto-Discovery**: Automatically finds and loads the newest `PawPatrol-*.txt` log file in `%LOCALAPPDATA%\PawPatrol` if no file path is specified.
6. **Flexible Output**: Supports standard stripped output, inline timestamps (`-t`), standardized clean format (`--clean`), structured JSON (`--json`), and raw unstripped mode (`--raw`).

---

## Quickstart & Common Commands

### 1. Converting Timestamps to IST (All Logs)

Convert all UTC timestamps to IST across the entire log file (without filtering out any module):

```powershell
# Display all logs with timestamps converted to IST
python filter_logs.py -f path/to/log.txt --to-ist

# Convert with clean inline timestamps: [YYYY-MM-DD HH:MM:SS IST]
python filter_logs.py -f path/to/log.txt --to-ist -t

# Save converted output to a new file
python filter_logs.py -f input.log --to-ist -o input_ist.log

# Overwrite input file in-place with IST timestamps
python filter_logs.py -f input.log --to-ist -i

# Keep original raw headers (UX Information: 0 : ) with IST timestamps
python filter_logs.py -f path/to/log.txt --to-ist --raw
```

---

### 2. Filtering by Module

By default, the script filters for `Networking` logs (matching `[Networking]` and `[Cloud.Networking]`):

```powershell
# Filter Networking logs from the latest auto-detected PawPatrol log
python filter_logs.py

# Filter Networking logs from a specific file
python filter_logs.py -f app.log

# Filter for a specific module
python filter_logs.py -f app.log -m Chat
python filter_logs.py -f app.log -m Whiteboard
python filter_logs.py -f app.log -m FileSync

# Filter for multiple modules
python filter_logs.py -f app.log -m Networking,Chat

# Exact module match only (excludes submodules like Cloud.Networking)
python filter_logs.py -f app.log -m Networking --exact
```

---

### 3. Filtering by Severity Level

Filter logs by severity level (case-insensitive):

```powershell
# Show Warnings and Errors only (Warning, Error, Critical)
python filter_logs.py -f app.log -m Networking --min-level Warning

# Show Errors only
python filter_logs.py -f app.log -l Error

# Show Warnings and Errors with a severity tag ([WARN ], [ERROR])
python filter_logs.py -f app.log --min-level Warning --with-level
```

---

### 4. Searching & Keyword Grep

Search within log messages and stack traces:

```powershell
# Search for a keyword or regex pattern within Networking logs
python filter_logs.py -f app.log -m Networking -g "SendMessage"
python filter_logs.py -f app.log -m Networking -g "Connection refused"

# Case-sensitive search
python filter_logs.py -f app.log -m Networking -g "ClientMap" --case-sensitive
```

---

### 5. Time Range Filtering

Filter logs within an IST time window:

```powershell
python filter_logs.py -f app.log --start "2026-11-21 21:00:00" --end "2026-11-21 22:30:00"
```

---

### 6. Module Discovery Report

Scan a log file and see a breakdown of all modules present and their log level counts:

```powershell
python filter_logs.py -f app.log --list-modules
```

**Example Output:**
```text

----------------------------------------------------------------------

FileSync                            | 12      | 12     | 0      | 0

```

---

### 7. Output Formats

```powershell
# Standardized clean single-line format: [TIMESTAMP IST] [LEVEL] [MODULE] Message
python filter_logs.py -f app.log -m Networking --clean

# Export matching entries as JSON objects
python filter_logs.py -f app.log -m Networking --json -o networking_logs.json

# Retain original unstripped raw lines (UX Information: 0 : ...)
python filter_logs.py -f app.log -m Networking --raw

# Pipe logs via stdin
cat app.log | python filter_logs.py -m Networking -t
```

## Options & Arguments Reference

| Option | Shorthand | Description |
| :--- | :--- | :--- |
| `--to-ist`, `--convert-to-ist` | | Convert all UTC timestamps to IST across **all logs** (bypasses module filter). |
| `-f <files...>` | `--file` | Path(s) to log files (supports wildcards). If omitted, finds latest PawPatrol log. |
| `-m <modules...>` | `--module` | Module name(s) to filter by (default: `Networking`). Use `all` or `*` for all modules. |
| `--exact` | | Require exact module tag match instead of substring match. |
| `-t` | `--timestamp` | Prepend inline `[YYYY-MM-DD HH:MM:SS IST]` timestamp to each entry. |
| `--with-level` | | Prepend `[INFO ]`, `[WARN ]`, or `[ERROR]` tag to each entry. |
| `--no-datetime` | | Suppress trailing `DateTime=...` metadata lines. |
| `--raw`, `--keep-prefix` | | Keep original process and trace header prefix (`UX Information: 0 : `). |
| `-l <level>` | `--level` | Filter by exact level (`Information`, `Warning`, `Error`, etc.). |
| `--min-level <level>` | | Filter for logs with this level or higher. |
| `-g <pattern>` | `--grep` | Filter entries matching a regex or keyword. |
| `--case-sensitive` | | Make `--grep` search case-sensitive. |
| `--start <timestamp>` | | Include entries at or after this IST timestamp. |
| `--end <timestamp>` | | Include entries at or before this IST timestamp. |
| `-o <file>` | `--output` | Write output to the specified file. |
| `-i` | `--in-place` | Overwrite the input log file in-place with the converted output. |
| `--clean` | | Format logs as `[TIMESTAMP IST] [LEVEL] [MODULE] message`. |
| `--json` | | Output entries as structured JSON. |
| `--list-modules` | | Print summary of all modules discovered with log counts. |
| `--stats` | | Append total match statistics to output. |
